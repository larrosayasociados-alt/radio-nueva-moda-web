# Radio Nueva Moda — web interactiva

Web estática para escuchar el directo, pedir temas según el programa en antena y compartir en redes.

## Qué hace
- Player con el stream oficial `stream.integracionvirtual.com/proxy/radionuevamoda`
- Detecta el programa actual en hora de Canarias (`Atlantic/Canary`)
- Formulario de petición / saludo que abre WhatsApp de cabina (`+34 625 39 17 79`)
- Compartir en WhatsApp, Facebook y portapapeles
- Historial local de peticiones (este dispositivo)
- Enlaces a Facebook, Instagram, apps Android e iOS

## Editar
Todo lo comercial está en `config.js`.
